# Fullstack Login & Signup System

A complete **Full-Stack Authentication System** built using modern web technologies.  
This project demonstrates secure user authentication with a clean UI, backend APIs, and database integration.

---

## 🚀 Features
  
- User **Signup & Login**
- Secure **password hashing** using bcrypt
- **MySQL database** integration
- **Environment variables** for sensitive data
- Clean **responsive UI**
- Separated **Frontend & Backend**
- Production-ready project structure
---


## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3 (Dark UI, animations, responsive design)
- JavaScript (Fetch API)

### Backend
- Node.js
- Express.js
- MySQL
- bcryptjs
- dotenv
- cors
